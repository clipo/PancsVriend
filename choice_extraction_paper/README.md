# Choice-extraction paper

Working folder for the paper on exact choice probabilities for grammar-constrained LLM agents.
This paper is separate from the Schelling paper in `paper/`.

| File | What it holds |
|---|---|
| `venues_and_deadlines.md` | Target venue, dates, fallbacks, decision gates |
| `paper_checklist.md` | Everything the paper needs before submission, with status |
| `todo_experiments.md` | Experiments and analyses (E0 to E9, other choice types) |
| `todo_draft.md` | Writing to-dos: sections, figures, tables, references |
| `draft/` | The LaTeX draft (`main.tex`); see `draft/README.md` to build it |
| `../value_functions/first_token/TODO.md` | Code to-dos for the first-token comparison |

Conventions:
- Dates marked **assigned** are working targets and can move. Dates marked **real** are external deadlines.
- `\tbd{...}` in the LaTeX marks a number or sentence still waiting on an experiment.
- Last updated: 18 Nov 2026.
